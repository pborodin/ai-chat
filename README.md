# Локальный ИИ Чат с поддержкой ИИ-Агентов (Tools)

Проект представляет собой полноценное веб-приложение для общения с локальными большими языковыми моделями (LLM).

### 🚀 Основные возможности:
* **Потоковый вывод (Streaming):** Токены ответов выводятся на экран в реальном времени через протокол Server-Sent Events (SSE).
* **Поддержка ИИ-Инструментов (Tools / Function Calling):** Локальная модель умеет автоматически вызывать Java-методы бэкенда для выполнения бизнес-логики (например, запрос биржевых котировок).
* **Прозрачное логирование шагов агента:** Все вызовы инструментов отображаются на фронтенде в виде отдельных системных сообщений-плашек, а финальные ответы выводятся следом.
* **Полноценная история:** Все созданные комнаты и turn-by-turn контекст общения автоматически сохраняются в файловую базу данных SQLite.

---

## 🛠️ Архитектурный стек

* **Бэкенд:** Java 21, Spring Boot 4.0.6, Spring AI 2.0.0-RC1 (Ollama Starter & JDBC Chat Memory Repository).
* **Фронтенд:** Vue.js 3 (Composition API), Vite, Native EventSource (SSE).
* **База данных:** SQLite 3 (Файловая БД, не требует установки отдельного сервера).

## 📦 Быстрый старт: Сборка и Запуск

### 1. Подготовка окружения (Ollama)
Убедитесь, что у вас установлена и запущена утилита [Ollama](https://ollama.com). Скачайте рекомендуемую базовую модель общего назначения с поддержкой инструментов:
```bash
ollama run qwen2.5:7b
```

### 2. Запуск Бэкенда (Spring Boot)
Перейдите в директорию бэкенда и запустите приложение. Для корректного отображения системных логов и эмодзи в консоли Windows обязательно передавайте флаг кодировки UTF-8:

* **Через стандартную командную строку Windows (CMD):**
  ```cmd
  set MAVEN_OPTS=-Dfile.encoding=UTF-8
  mvn spring-boot:run
  ```
* **Через PowerShell / Терминал VS Code / IntelliJ IDEA:**
  ```powershell
  \$env:MAVEN_OPTS="-Dfile.encoding=UTF-8"
  mvn spring-boot:run
  ```

Бэкенд запустится на порту `8080`. Файл базы данных `local_chat.db` создастся автоматически в корневой папке.

### 3. Запуск Фронтенда (Vue.js 3)
Перейдите в директорию фронтенда, установите зависимости и запустите сервер для разработки:
```bash
npm install
npm run dev
```
Фронтенд откроется в браузере по адресу `http://localhost:3070`.


### 4. Сборка проекта в единый jar файл  
Для сборки **jar** перейдите в папку backend и выполните команду
```bash
mvn clean package
```

## ⚙️ Конфигурация параметров (`application.properties`)

Все ключевые настройки бэкенда находятся в файле `backend/src/main/resources/application.properties`.

### Настройки подключения к SQLite
* `spring.datasource.url=jdbc:sqlite:local_chat.db` — Путь к файлу базы данных.
* `spring.datasource.driver-class-name=org.sqlite.JDBC` — Драйвер для работы с SQLite.
* `spring.ai.chat.memory.repository.jdbc.initialize-schema=always` — Автоматическое создание служебных таблиц Spring AI для истории чата при запуске. Возможные режимы: `always` (выполнять скрипты всегда), `never` (отключено).

### Настройки локальной модели (Ollama)
* `spring.ai.ollama.base-url=http://localhost:11434` — Ссылка на локально запущенный сервис Ollama.
* `spring.ai.ollama.chat.options.model=qwen2.5:7b` — Название используемой модели.
* `spring.ai.ollama.chat.options.temperature=0.2` — Степень «творчества» модели. Для работы с инструментами и строгого следования логике рекомендуется выставлять значения от `0.1` до `0.3`. Высокие значения (например, `0.7`) могут привести к галлюцинациям в JSON-структурах инструментов.

## 🧹 Обслуживание и Очистка Базы Данных

Если в процессе разработки локальная модель сгенерировала ломаный или недописанный JSON-вызов инструмента, этот ошибочный контекст сохранится в SQLite. При последующих запросах модель будет читать историю и повторять ошибку.

### Способ 1. Полный сброс (Рекомендуется для разработки)
1. Полностью остановите бэкенд-приложение.
2. Физически удалите файл `local_chat.db` из корневой папки проекта.
3. Запустите бэкенд заново. Благодаря режиму `initialize-schema=always` пустая база данных со всеми необходимыми таблицами пересоздастся автоматически.

### Способ 2. Точечная очистка через SQL-клиент
Если вы не хотите терять список комнат, но вам нужно очистить историю сообщений конкретного зависшего чата, откройте файл `local_chat.db` через любой менеджер БД (например, DBeaver, DataGrip или плагин для вашей IDE) и выполните команды:

```sql
-- Посмотреть сохраненный контекст сообщений ИИ
SELECT * FROM chat_history;

-- Очистить историю сообщений для конкретной зависшей сессии
DELETE FROM chat_history WHERE conversation_id = 'ИД_ВАШЕГО_ЧАТА';
```
